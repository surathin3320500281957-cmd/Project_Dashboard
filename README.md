# แดชบอร์ดหน่วยความรับผิดชอบ — การเคหะแห่งชาติ

เอกสารนี้สรุปโครงการแดชบอร์ด เผื่อไว้สำหรับเปิดแชทใหม่แล้วอ้างอิงต่อได้ทันที (คล้ายรูปแบบ README ของ `Laa_Dashboard`)

---

## 1) ภาพรวมโครงการ

แดชบอร์ดแบบ **ไฟล์ HTML เดียว** (single-file, ไม่มี backend, ไม่ต้องเชื่อมอินเทอร์เน็ต) สำหรับสรุปและตรวจสอบข้อมูล "หน่วยความรับผิดชอบ" ของฝ่ายบริหารทรัพย์สิน ชบ. — สร้างจากไฟล์ Excel `DBหน่วยความรับผิดชอบ.xlsx` ชีต **"สรุปหน่วยเต็ม"** (185 โครงการ / 17 สำนักงาน / 3 กอง)

**ไฟล์ล่าสุด:** `LAA_Dashboard_หน่วยความรับผิดชอบ.html` (~0.84MB)

---

## 2) แหล่งข้อมูลต้นทาง

ไฟล์ Excel มี 6 ชีต:

| ชีต | หน้าที่ |
|---|---|
| `อธิบาย` | หมายเหตุ SQL query ที่ใช้ดึงข้อมูล (ไม่ใช่ข้อมูลจริง) |
| **`สรุปหน่วยเต็ม`** | **ชีตหลักที่แดชบอร์ดใช้** — 185 แถว × 34 คอลัมน์ |
| `หน่วยว่าง` | ข้อมูลระดับหน่วย (4,822 แถว) — ใช้ join คำนวณสถานะ "ว่าง" |
| `เช่าซื้อรอโอน` | ข้อมูลระดับหน่วย (8,566 แถว) — ใช้ join คำนวณ "ติดค้ำประกัน/รอโอน" |
| `มีสัญญา` | ข้อมูลระดับหน่วย (17,820 แถว) — ใช้ join คำนวณ "เช่า/เช่าซื้อ/จะซื้อจะขาย" |
| `เช่าเหมา` | ข้อมูลระดับหน่วย (11,796 แถว) — ใช้ join คำนวณ "เช่าเหมา" |

### สูตรในชีต "สรุปหน่วยเต็ม"
คอลัมน์ A-U (ข้อมูลพื้นฐาน + หน่วยเต็ม) เป็นค่าคงที่ (กรอกมือ) ส่วนคอลัมน์สถานะหน่วย (เช่า/เช่าเหมา/เช่าซื้อ/ติดค้ำประกัน/รอโอน/ว่าง 4 แบบ) เป็นสูตร `COUNTIFS` ดึงจาก 4 ชีตธุรกรรมข้างต้น จับคู่ด้วย**รหัสโครงการ**เสมอ ส่วน "หน่วยโอนกรรมสิทธิ์" คำนวณจาก `หน่วยเต็ม − check` (check = ผลรวมของทุกสถานะที่ยังไม่โอน)

**✅ ตรวจทานแล้ว:** จำลองสูตร COUNTIFS ทั้ง 10 ตัวด้วย Python แล้วเทียบกับผลรวมจริงในไฟล์ — **ตรงกัน 100%**

## 3) สถาปัตยกรรมไฟล์ (เทคนิคบีบอัด)

ไฟล์เดียวจบ ไม่มีไฟล์แยก ไม่มี backend ใช้เทคนิค **gzip + base64** ฝังข้อมูลเป็นตัวแปร JS:

```
ขั้นตอนตอนสร้างไฟล์ (ทำครั้งเดียว):
1. แปลงแต่ละแถวเป็น array (ไม่ใช่ object ซ้ำคีย์) → {cols:[...], rows:[[...],[...]]}
2. JSON.dumps แบบไม่มีช่องว่าง (separators=(',',':'))
3. gzip compress (level 9)
4. base64 encode → เก็บในตัวแปร DB64 (ข้อมูลหลัก) และ PB64 (ข้อมูลตรวจสอบ)

ขั้นตอนตอนเปิดไฟล์ (ฝั่งเบราว์เซอร์):
DB64/PB64 → atob() → DecompressionStream('gzip') (Web API มาตรฐาน ไม่ต้องใช้ไลบรารีเพิ่ม)
→ JSON.parse → คืนรูป array-of-objects ด้วย cols mapping
```

| ชุดข้อมูล | เนื้อหา | ขนาดดิบ | หลังบีบอัด | อัตราส่วน |
|---|---|---|---|---|
| `DB64` | 185 โครงการ × 38 คอลัมน์ | 143.6 KB | 13.6 KB | ~10.6× |
| `PB64` | 38,880 รายการตรวจสอบระดับหน่วย × 6 คอลัมน์ | 3.62 MB | 334 KB | ~10.8× |

**ไลบรารีที่ฝังในไฟล์ (inline, ไม่มี CDN ภายนอก — กันปัญหาเครือข่ายองค์กรบล็อก CDN):**
- Chart.js (UMD, 204KB) — ใช้สำหรับกราฟโดนัทเท่านั้น
- SheetJS `xlsx.mini.min.js` (248KB) — สำหรับ export Excel

**ข้อกำหนดเบราว์เซอร์:** ต้องรองรับ `DecompressionStream` (Chrome/Edge 80+, Firefox 113+, Safari 16.4+) — ถ้าไม่รองรับจะมีข้อความแจ้งเตือนแทนหน้าเปล่า

## 4) โครงสร้างข้อมูลที่ใช้ (field list)

**RAW_DATA** (185 แถว, จากชีตสรุปหน่วยเต็ม): `no, dept, div, office_code, office_name, proj_type, income_model, building_char, building_form, proj_code, proj_name, address, zone, province, income_level, proj_group, community_care, utility_transfer, building_count, juristic_count, units_total, units_transferred, units_rent, units_lease_whole, units_hire_purchase, units_pending_sale, units_guarantee, units_pending_transfer, staff_house, vacant_ready_rent, vacant_notready_rent, vacant_ready_sale, vacant_notready_sale, check, vacant_total, active_total, vacant_ready_total, vacant_notready_total`

**AUDIT_DATA** (38,880 รายการ, จาก 4 ชีตธุรกรรม, group by `proj_code`): `s` (ที่มา: C=มีสัญญา, L=เช่าเหมา, P=เช่าซื้อรอโอน, V=หน่วยว่าง), `h` (บ้านเลขที่), `m` (เลข MAT), `b` (bucket สถานะ), `n` (หมายเหตุ/สถานะจริง — เฉพาะ P, V)

**⚠️ ตัดข้อมูลส่วนบุคคลออกทั้งหมด** (ไม่มีชื่อลูกค้า/เลขบัตร ปชช./เบอร์โทร) — เก็บเฉพาะฟิลด์ที่จำเป็นสำหรับตรวจสอบยอด

## 5) ฟีเจอร์ในแดชบอร์ด

### การ์ด KPI (4 ใบ, คลิกเลือกเมตริกได้)
| การ์ด | สูตร | สี |
|---|---|---|
| หน่วยเต็ม | `units_total` | น้ำเงิน-ม่วง (hero gradient) |
| หน่วย Active | เช่า+เช่าเหมา+เช่าซื้อ+จะซื้อจะขาย+ติดค้ำประกัน+รอโอน | เขียวมิ้นท์ |
| ว่างพร้อมขาย | เพื่อเช่า+เพื่อขาย | ทอง |
| ว่างไม่พร้อมขาย | เพื่อเช่า+เพื่อขาย | แดง |

คลิกการ์ดแล้วกางดู breakdown รายรายการ + กราฟ 3 ตัวด้านล่างเปลี่ยนตามเมตริกที่เลือกทันที

### กราฟ (ผูกกับเมตริกที่เลือกจากการ์ด)
- **โดนัทกอง** — Chart.js, แสดงตัวเลข static บนชิ้นกราฟ (ปลั๊กอินเขียนเอง ไม่ใช้ไลบรารีเสริม)
- **อันดับสำนักงาน Top 10** และ **อันดับโครงการ Top 10** — ไม่ใช้ Chart.js แต่เป็น custom HTML bar: แท่งสีไล่เฉด (rainbow 10 สี) + ป้ายชื่อเป็นแคปซูลสีม่วง (`#5B3E96`) ตัวหนังสือขาว + ป้ายตัวเลขสีเข้มอยู่ท้ายแถวเสมอ (กันปัญหาทับกัน)

### ตัวกรอง
กอง, ประเภทโครงการ, กลุ่มโครงการ, รูปแบบการหารายได้, ลักษณะอาคาร, จังหวัด + ค้นหาอิสระ พร้อม **filter chip สีต่างกันตามมิติ** ใต้แถบตัวกรอง กดลบทีละตัวได้

### ตารางสรุป (กอง → สำนักงาน)
Group by กอง (แถบสีไฮไลต์ + ยอดรวม) → สำนักงานย่อยด้านล่าง คลิกหัวคอลัมน์เรียงลำดับได้

### ตารางรายละเอียดโครงการ
คอลัมน์ครบทุกตัวกรอง (กอง/ประเภท/กลุ่มโครงการ/รูปแบบหารายได้/ลักษณะอาคาร/จังหวัด) + หน่วยเต็ม/โอนแล้ว/ว่าง คลิกแถวกางดู:
- ฟิลด์เพิ่มเติมของโครงการ (ที่อยู่, โซน, ระดับรายได้ ฯลฯ)
- **"ตรวจสอบข้อมูล"** — รายการระดับหน่วยจริงจาก AUDIT_DATA จัดกลุ่มตามสถานะ (แสดงตัวอย่าง 30 รายการ/กลุ่ม + จำนวนรวม)

### Export (แยกอิสระต่อตาราง — ตารางสรุปและตารางรายละเอียด)
ปุ่มอยู่เหนือแต่ละตาราง:
- **PDF (แดง)** — เปิดแท็บใหม่ แสดงรายงานพร้อมพิมพ์ (A4 แนวนอน) มีปุ่ม "พิมพ์/บันทึกเป็น PDF" ในตัว
- **Excel (เขียว)** — export .xlsx เฉพาะข้อมูลตารางนั้นตามตัวกรองปัจจุบัน

## 6) ประวัติการพัฒนา (สรุปย่อ)

1. สร้างแดชบอร์ดเริ่มต้น (การ์ด/ฟิลเตอร์/กราฟ/ตาราง/export) จากไฟล์ Excel ที่อัปโหลด
2. แก้บั๊กกราฟว่างเปล่า (CDN ถูกบล็อก) → ฝังไลบรารีในไฟล์ทั้งหมด, ปรับตารางสรุปเป็น group by กอง, ปรับสีสดใส
3. จำกัด export ให้เหลือเฉพาะตารางสรุป+รายละเอียด, PDF เปิดแท็บใหม่แทน print ทั้งหน้า
4. ย้ายปุ่ม export ไปไว้เหนือแต่ละตาราง (แยกอิสระ, สี PDF แดง/Excel เขียว)
5. ตรวจทานจำนวนสำนักงาน (17 ไม่ใช่ 19) และตรวจสอบสูตร COUNTIFS ทั้งหมดในชีต
6. ปรับ KPI เหลือ 4 การ์ด (หน่วยเต็ม/Active/ว่างพร้อมขาย/ว่างไม่พร้อมขาย) ตามที่กำหนดใหม่
7. เพิ่ม breakdown ในการ์ด, กราฟผูกกับเมตริกที่เลือก, audit drill-down จาก 4 ชีตธุรกรรม (ตัด PII), filter chip สี
8. บีบอัด+กระจายไฟล์ (LZ-string + multi-file zip) — เวอร์ชันทดลอง
9. เปลี่ยนเทคนิคบีบอัดเป็น **gzip+base64+DecompressionStream** กลับมาเป็นไฟล์เดียวตามที่กำหนด (0.85MB)
10. ปรับกราฟ ranking เป็น custom HTML (สีไล่เฉด + badge) ตามภาพตัวอย่าง
11. ปรับป้ายชื่อเป็นแคปซูลม่วง + เพิ่ม label ค่าแบบ static บนโดนัท

## 7) หากเปิดแชทใหม่

แนบไฟล์ต่อไปนี้พร้อมกับ README นี้:

- ไฟล์แดชบอร์ดปัจจุบัน `LAA_Dashboard_หน่วยความรับผิดชอบ.html` (ถ้าจะแก้ไขต่อจากของเดิม)

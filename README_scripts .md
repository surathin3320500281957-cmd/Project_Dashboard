# สคริปต์ประมวลผลข้อมูล — แดชบอร์ดหน่วยความรับผิดชอบ

**ไฟล์เดียวจบ** — `rebuild_dashboard.py` ดึงข้อมูลจาก Excel + เข้ารหัส + ฝังเข้า `index.html` ให้อัตโนมัติทั้งหมด (รวม 6 สคริปต์เดิมเข้าด้วยกันแล้ว)

**สำคัญ:** ไฟล์นี้อยู่ใน container ชั่วคราวของ Claude เท่านั้น จะหายไปทุกครั้งที่เปิดแชทใหม่ — เก็บไว้ที่ GitHub repo นี้เพื่อให้แชทใหม่ในอนาคตดึงกลับมาใช้ได้ทันที (Claude เข้าถึง `raw.githubusercontent.com` ได้โดยตรงจากเครื่องมือรันโค้ด)

## วิธีใช้ในแชทใหม่

บอก Claude ว่า: *"สคริปต์อยู่ที่ https://raw.githubusercontent.com/[user]/[repo]/main/scripts/rebuild_dashboard.py ดึงมาใช้ได้เลย"* — Claude ดึงมาวางใน container แล้วรันได้ทันที

## วิธีรัน

```bash
pip install openpyxl --break-system-packages   # ถ้ายังไม่มี
python3 rebuild_dashboard.py
```

**ก่อนรันต้องมี:**
- `/mnt/user-data/uploads/DBหน่วยความรับผิดชอบ.xlsx` (ไฟล์ Excel ต้นทาง)
- `index.html` วางอยู่**โฟลเดอร์เดียวกับสคริปต์** (ไฟล์แดชบอร์ดที่จะแทนที่ข้อมูลให้)

**ทำให้อัตโนมัติทั้งหมด:**
1. ดึงข้อมูลระดับโครงการ (185 แถว)
2. ดึงหน่วย Active จาก 3 ชีตธุรกรรม
3. ดึงหน่วยว่างใหม่+เดิม พร้อม**เช็ค MAT ซ้ำกับเช่าเหมาอัตโนมัติ**
4. เทียบหน่วยว่างเก่า-ใหม่ 5 กลุ่ม พร้อมเช็คสมการอนุรักษ์อัตโนมัติ
5. ดึงผลสำรวจกายภาพ+ลิงก์รูป พร้อมเช็ค join match rate
6. เข้ารหัส gzip+base64 ทั้ง 7 ก้อน (DB64/PB64/CS64/PF64/VC64/CH64/SV64)
7. **แทนที่ค่าใน `index.html` ให้เองอัตโนมัติ** (ไม่ต้องแก้ไฟล์ด้วยมือแล้ว)

ทุกขั้นตอนพิมพ์ตัวเลขตรวจสอบออกมาให้ไล่เช็คได้ (✅/❌/⚠️ กำกับไว้ชัดเจน) — ถ้าเจอ ❌ หรือ ⚠️ ให้หยุดตรวจสอบก่อน อย่าใช้ไฟล์ที่ได้ต่อ

## จุดที่ต้องระวัง (อ่านก่อนรันทุกครั้ง)

1. **ตรวจสูตร COUNTIFS ในชีต "สรุปหน่วยเต็ม" ก่อนรันทุกครั้ง** — ถ้าสูตรเปลี่ยน ต้องแก้เงื่อนไขใน STEP 2/3 ของสคริปต์ (มีคอมเมนต์กำกับตำแหน่งไว้ในโค้ด) ให้ตรงก่อน
2. **แก้ปี พ.ศ. → ค.ศ.** เมื่อดึงวันที่จากชีต "อธิบาย" มาใช้ต่อ (สคริปต์นี้ไม่ได้จัดการส่วน `lastUpdated`/`.timeframe-banner` ให้ ต้องอัปเดตเองแยกหลังรันถ้าวันที่เปลี่ยน — ดู README หลักหัวข้อ 1.2)
3. **ทดสอบด้วย Node.js + jsdom จำลองคลิกจริงทุก tab ก่อนส่งมอบเสมอ** — สคริปต์นี้แค่ฝังข้อมูล ไม่ได้ตรวจ syntax หรือทดสอบ UI ให้ ต้องทำแยกหลังรันเสร็จ
4. ถ้า `index.html` ไม่พบในโฟลเดอร์เดียวกัน สคริปต์จะบันทึกเป็นไฟล์ `.txt` แยกให้แทน (เผื่อกรณีต้องเข้ารหัสอย่างเดียวโดยยังไม่มีไฟล์แดชบอร์ดอยู่ใกล้ๆ)

## ทดสอบแล้วว่าใช้งานได้จริง

รันเทียบกับไฟล์ Excel ฉบับล่าสุดแล้ว — ข้อมูลทั้ง 7 ก้อนที่ได้ **เหมือนกันทุกตัวอักษรกับที่เคยทำด้วย 6 สคริปต์แยกก่อนหน้านี้** (เทียบ JSON content ตรงๆ ไม่ใช่แค่ดู log)
